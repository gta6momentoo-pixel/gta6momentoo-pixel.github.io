ClipFactory

ClipFactory is a private desktop tool used by the GTA6Moments channel owner to cut long gameplay recordings into short clips.

It connects to YouTube with read-only access (YouTube Data API and YouTube Analytics API) to read the owner's own channel statistics, such as views and average view percentage, so it can learn which clips perform best. It never uploads, edits, comments on, or deletes anything on YouTube. Uploading is always done manually by the channel owner.
